\# TranscribeFlow



Универсальный транскрибатор видео с YouTube, Rutube, VK Video.



\## Возможности



\- Скачивание аудио с YouTube, Rutube, VK Video

\- Транскрибация речи (Vosk, офлайн)

\- Тайминги по сегментам

\- Нейрокоррекция текста (YandexGPT)

\- Веб-интерфейс (Flask)

\- Desktop-приложение (PySide6)



\## Установка



1\. Установить Python 3.12

2\. Скопировать проект

3\. Скачать FFmpeg и Vosk модель (см. ниже)

4\. Запустить `setup.bat`

5\. Запустить `start\_web.bat` или `start\_desktop.bat`



\## Что нужно скачать отдельно



\- \*\*FFmpeg\*\*: https://www.gyan.dev/ffmpeg/builds/

&#x20; Распаковать в `transc/ffmpeg-master-latest-win64-gpl/`



\- \*\*Vosk модель\*\*: https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip

&#x20; Распаковать в `transc/vosk-model-small-ru-0.22/`
